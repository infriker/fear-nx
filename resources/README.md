# Application icon

`icon.jpg` is the F.E.A.R. icon from the Steam desktop shortcut, converted from
its largest 48×48 icon entry to the 256×256 baseline JPEG required by the NRO
packager. CMake embeds it in the Homebrew Menu assets when building the NRO.
The original artwork remains the property of its respective rights holders;
the project's source-code license does not relicense it.
